## CAD quick rules

1. Barrel diameter is **8.9 mm** for all four current pens; fork **length** and
   **charge UX**, not diameter.
2. Pro / 2nd gen: magnetic **attach + pair + wireless charge** on iPad edge —
   sleeves must not block the flat magnet face if charge-on-iPad is required.
3. USB-C: magnetic attach is **storage only**; charge via **sliding USB-C** end —
   leave slider travel clear.
4. **iPhone Duo** officially lists **Apple Pencil (USB-C) only** (enablement
   “coming later this year” in some Apple FAQ/Newsroom text as of this
   checkpoint).
5. No public Pencil dimensional drawings; tip thread unpublished — measure tips
   before locking spare cavities.
