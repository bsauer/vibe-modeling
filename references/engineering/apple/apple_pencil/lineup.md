# Apple Pencil — current lineup and compatibility

Primary: [apple.com/apple-pencil](https://www.apple.com/apple-pencil/), Support
tech-specs linked below. Checkpoint **2026-10-22**.

## Models still sold new

None of the four pens is discontinued on the live US catalog.

### Apple Pencil Pro — [Support 120123](https://support.apple.com/en-us/120123)

| Field | Value |
|---|---|
| Introduced | 2024 |
| Part (US) | MX2D3AM/A |
| Size | 166 × Ø 8.9 mm; 19.15 g |
| Charge / pair | Magnetic attach on iPad side — pairs and wirelessly charges |
| Features | Pressure, tilt, hover (supported iPads), double-tap, squeeze, barrel roll, haptics, Find My |
| System | iPadOS 17.5+ |
| Compatibility | iPad Pro 13/11 (M4, M5); iPad Air 13/11 (M2, M3, M4 where listed); iPad mini (A17 Pro) — see Support for full list |

### Apple Pencil (USB-C) — [Support 121318](https://support.apple.com/en-us/121318)

| Field | Value |
|---|---|
| Introduced | 2023 |
| Part (US) | MUWA3AM/A |
| Size | 155 × Ø 8.9 mm; 20.5 g |
| Charge / pair | USB-C under sliding cap; Bluetooth |
| Magnetic attach | Yes — **storage only** (no wireless charge/pair on edge) |
| Features | Tilt; hover on supported iPads; **no** pressure sensitivity; no double-tap / squeeze |
| System | iPadOS 17.1.1+ |
| Compatibility | Broad USB-C iPad set (Pro/Air/mini/base generations per Support); **also listed for iPhone Duo** |

### Apple Pencil (2nd generation) — [Support 111889](https://support.apple.com/en-us/111889)

| Field | Value |
|---|---|

| Part (US) | MXN43AM/A |
| Size | 166 × Ø 8.9 mm; 18.2 g |
| Charge / pair | Magnetic attach — pairs and wirelessly charges |

| Compatibility | Older USB-C iPad Pro / Air / mini generations per Support (not the newest Pro-only-Pro set) |

### Apple Pencil (1st generation) — [Support 111920](https://support.apple.com/en-us/111920)

| Field | Value |
|---|---|
| Introduced | 2015 |
| Part (US) | MYQW3AM/A |
| Size | 175.7 mm tip-to-cap × Ø 8.9 mm; 20.7 g |
| Charge / pair | Lightning plug; USB-C iPads need **USB-C to Apple Pencil Adapter** |
| Magnetic | Cap magnet only — not side-of-iPad wireless charge |
| Features | Pressure, tilt |
| Box | Includes extra tip; adapter required for some USB-C iPads (also sold separately) |

## Tip and adapter accessories

| Accessory | Part | Notes |
|---|---|---|
| Apple Pencil Tips – 4 pack | MX763AM/A | Fits **all four** current pens |
| USB-C to Apple Pencil Adapter | MWML3AM/A | For 1st gen on USB-C iPads |

Tips unscrew; serial for Pro / 2nd / USB-C is under the tip
([Support 109031](https://support.apple.com/en-us/109031)). **No** Apple-published
thread pitch or tip OD.

## iPhone Duo

| Pencil | Duo support |
|---|---|
| USB-C | **Yes** — listed on Duo / USB-C compatibility; some Apple text says enablement “coming later this year” |
| Pro / 2nd / 1st | **No** (iPad-only lists) |

Duo display Pencil notes also appear in Duo research under
`references/engineering/apple/iphone_duo/`. Prefer Support + Duo specs when
they disagree with secondary roundups.

## Feature matrix (marketing / Support)

| Feature | Pro | USB-C | 2nd gen | 1st gen |
|---|---|---|---|---|
| Pressure | Yes | No | Yes | Yes |
| Tilt | Yes | Yes | Yes | Yes |
| Hover | Yes* | Yes* | Yes* | No |
| Double-tap | Yes | No | Yes | No |
| Squeeze / barrel roll / haptics / Find My | Yes | No | No | No |
| Side magnetic charge+pair | Yes | Storage only | Yes | No |
| Wired charge | — | USB-C | — | Lightning (+ adapter path) |

\*Hover only on iPads that support Apple Pencil hover.
