## Naming collision

`designs/iphone-duo/` currently holds MagSafe **desk-stand / plate** print
assets whose filenames also use “Duo.” Those are **not** Apple iPhone Duo
phone geometry. Use this `references/engineering/apple/iphone_duo/` tree for
the foldable phone and Apple cases.
